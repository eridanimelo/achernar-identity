# Jira Skills

A integração Jira é genérica.

- O projeto ativo vem de `config/jira.yaml`.
- Agents MUST NOT hardcodar um projeto específico ou qualquer outro projeto.
- Dados críticos devem ser validados via MCP quando configurado.
- O mesmo framework pode ser usado por diferentes equipes/projetos apenas alterando a configuração.
