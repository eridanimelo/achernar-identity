# Decisões de implementação
Autorização humana de 24/10/2026 delega decisões e execução integral, sobrepondo as paradas entre fases do motor. Origem NEW confirmada. Stack preservada de config/technology.yaml: Java 25, Spring Boot 4.1, Spring JDBC, PostgreSQL 18, Angular 22, Material, Liquibase. SQL nativo explicitamente permitido pelo solicitante; sem ORM, Lombok ou relacionamentos de objetos. Slices agrupam controller, service e persistência por capacidade; conta e credenciais são agregado único, com acesso compartilhado ao repository de usuários. Leituras sem consistência transacional usam NOT_SUPPORTED; operações de credencial/escrita usam transação e bloqueio quando necessário. JWT RS256 com chave persistida, validade de 15 minutos, cookie HttpOnly e versão de credencial validada em cada requisição. CSRF obrigatório. Sem refresh token nesta entrega; sessão restaura por cookie até expirar. Google adiado. Primeiro ADMIN via configuração externa. E-mail usa outbox transacional com tentativas; mensagens removidas após envio. Bootstrap não modifica administrador existente. Frontend feature-based com separação de arquivos e componentes de apresentação.
Pacote corporate/ui-ux inexiste: usada skill ui-ux-design sem alterar corporate. Repositório contém somente master, sem develop: branch de trabalho criada a partir do único estado inicial disponível; nenhum push será executado.
