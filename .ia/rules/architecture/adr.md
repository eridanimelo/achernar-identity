# Architecture Decision Record

Criar ADR quando houver decisão arquitetural relevante.

Exemplos:
- mudança de arquitetura;
- nova integração estrutural;
- escolha de padrão arquitetural;
- alteração significativa de persistência;
- decisão com impacto em múltiplas features.

MUST NOT criar ADR para decisões triviais de implementação.

Uma ADR deve registrar:
- contexto;
- decisão;
- alternativas consideradas;
- consequências.
